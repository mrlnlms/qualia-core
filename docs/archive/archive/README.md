# Archive

Esta pasta contém scripts e outputs antigos que foram usados durante o desenvolvimento.

## Conteúdo
- `scripts_debug/` - Scripts de debug e correção usados durante desenvolvimento
- `test_outputs/` - Outputs de teste antigos

Estes arquivos são mantidos para referência histórica.

## Material local fora do Git

As pastas `morto/` e `backups/` contêm cópias locais de documentos, scripts e
backups aposentados. Elas são ignoradas pelo `.gitignore`, assim como os
rascunhos `backlog_llm_novo.md` e `readme-*-2026-08-14.md`. Esses rascunhos não
representam o backlog nem a documentação aprovados.

O backup de junho de 2025, o setup antigo e os planos concluídos de backlog,
mutation testing e stress tests foram retirados da árvore versionada em
24/10/2026. As cópias locais foram preservadas, e os originais continuam
disponíveis no histórico Git. A mudança da spec de transcrição para
`plugins/documents/transcription_local/SPEC.md` permanece versionada.

O backlog atual está em `docs/BACKLOG.md`; o estado técnico está em
`docs/TECHNICAL_STATE.md`, e o estado da transcrição em
`docs/TRANSCRIPTION_STATUS.md`.
